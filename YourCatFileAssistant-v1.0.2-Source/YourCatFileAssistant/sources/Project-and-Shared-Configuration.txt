# 你的猫咪文件助手 · YourCatFileAssistant v1.0.2

Windows 本地文件工具与桌面猫咪助手，支持中英文界面。本 ZIP 是轻量、脱敏的**应用源码开发包**，不包含安装程序、.NET SDK、运行时、FFmpeg/7-Zip 二进制或第三方引擎源码归档。猫咪素材、UI、应用功能代码及测试样本完整保留。

## 项目结构

- `src/CatFileAssistant.Desktop`：C# / WPF 界面、桌宠、图标及 PNG/JSON 素材。
- `src/CatFileAssistant.Core`：核心模型、规则、双语文本。
- `src/CatFileAssistant.Infrastructure`：文件处理、配置、进程适配。
- `src/CatFileAssistant.ArchiveWorker`：独立归档工作进程及 7-Zip 互操作；保留 LGPL-2.1-or-later 声明。
- `shared`：共享配置、设计参数与原创恢复规则。
- `tests`：不依赖第三方测试框架的验收程序和固定测试素材；测试密码只是公开测试数据。
- `scripts`：依赖恢复、构建、验收及安装打包工具；`LocalizationMaintenance` 保留原先藏在 `.build` 下的本地化维护源码和翻译材料。
- `tools`：依赖来源、固定版本/哈希、许可和对应源码索引，不含已安装依赖。
- `docs`：架构、功能、设计与历史说明。历史运行报告、机器资料、截图和录屏因隐私未公开。

## 构建依赖

Windows x64；.NET SDK **10.0.401**（`global.json` 精确固定）；Python 3.11+；PowerShell 7（推荐）。应用使用 .NET 10 / WPF，无第三方 NuGet `PackageReference`；仍需由 SDK/NuGet 恢复 .NET 目标框架引用及必要的运行时包。NuGet 源仅 nuget.org，缓存写在当前项目 `tools/dotnet` 中。

运行依赖：固定 FFmpeg `n9.0.2-14-gebafaee10a-20260929` 和 7-Zip **26.04 x64**，详细 URL 与 SHA-256 见 `tools/*/provenance.json`。现有 FFmpeg 历史 URL 在本次联网检查返回 404，不能保证其仍可自动下载；脚本不会用 `latest` 静默替代。

### 恢复依赖

```powershell
# 安装上述 Python / PowerShell，并准备一个可用的固定 SDK，或让脚本下载 SDK。
# 有固定上游下载归档时：
./scripts/restore-dependencies.ps1 -FfmpegArchive 'X:/downloads/pinned-ffmpeg.zip' -SevenZipArchive 'X:/downloads/7z2604-x64.exe' -ExtractorPath 'X:/7zip/7z.exe'

# 推荐的离线恢复：从维护者另行提供的同版完整源码/依赖包中，按哈希恢复引擎。
./scripts/restore-dependencies.ps1 -SourceCompanion 'X:/downloads/你的猫咪文件助手-V1.0.2-Windows-x64-Sources.zip'
```

没有提供本地文件时，恢复脚本会尝试固定上游 URL，下载失败会明确终止。不要执行下载的 7-Zip 安装程序：脚本仅作为归档解包。直接恢复 7-Zip 需要开发机已安装 7-Zip 并通过 `-ExtractorPath` 指定；从完整配套包恢复时不需要额外解包器。

SDK 可预先安装在 PATH 或 `tools/dotnet/sdk`。若下载不通，可将微软对应 SDK ZIP 按 `scripts/bootstrap-sdk.ps1` 的 SHA-512 校验后解压到后者。使用系统 SDK 时可传 `-SkipSdk`。

完整配套包是维护者需要另行提供的较大文件；本轻量包不含它，也没有编造尚不存在的公开下载地址。发布者应在 GitHub Releases 同时提供可用的配套材料或长期镜像，否则新开发者可能无法取得已经下架的固定 FFmpeg。

第三方许可合并保留索引和必要声明；不影响程序源码与素材。大型历史依赖/构建索引及可再生成的本地化语料快照未放入小包；完整二进制发行前从原配套包恢复相应材料。当前翻译目录和本地化维护源码保留。
